`fluxmail folders rename`

Rename a folder in an email account, keeping it under the same parent folder

## Usage

```bash
fluxmail folders rename <folder> <name>
```

## Arguments

| Name | Required | Details | Default |
| --- | --- | --- | --- |
| `folder` | Yes | Folder ID from folders list, or the folder name | None |
| `name` | Yes | New name for the folder itself, without its parent path | None |

## Options

This command has no command-specific options.
