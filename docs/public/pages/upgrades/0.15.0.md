---
title: 'Upgrade to 0.15.0'
description: 'Move to Node.js 22.22 or later before installing Fluxmail 0.15.0.'
updated: '2026-10-16'
---

Fluxmail 0.15.0 requires Node.js 22.22 or later and no longer runs on Node.js 20. MCP tools, CLI commands, and REST requests work the same way as in 0.14.0, and the store format does not change.

## Who needs to act

If you installed Fluxmail with npm and run it on Node.js 20, upgrade Node.js before you upgrade Fluxmail. The Docker image already uses Node.js 22, so Docker installations need no changes.

## Upgrade Node.js

Check the version that runs Fluxmail:

```bash
node --version
```

If it reports `v20`, install Node.js 22.22 or later, then reinstall Fluxmail with the new Node.js:

```bash
npm install -g fluxmail@0.15.0
```

If your MCP client launches `fluxmail stdio` with a specific Node.js path, point it at the new installation and restart the client.
