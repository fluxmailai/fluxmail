---
title: 'Upgrade to 0.28.0'
description: 'Restart folder-filtered IMAP searches and back up the store before upgrading.'
updated: '2026-11-15'
---

Fluxmail 0.28.0 changes IMAP page tokens for folder-filtered lists and searches, and migrates the SQLite store to format 9.

## Restart affected searches

Discard saved page tokens from IMAP lists and searches that used a folder filter, including a folder role such as `inbox`. Restart the same request without a page token, then use the new response's `nextPageToken` to continue. Older tokens return `invalid_request`.

| Interface | Required changes |
| --- | --- |
| MCP | Omit `pageToken` when restarting an affected list or search, including each affected account in a batch search. |
| CLI | Omit `--page-token` when restarting an affected list or search. |
| REST | Omit `pageToken` when restarting an affected list or search, including each affected account in a batch search. |

Gmail, Outlook and IMAP searches without a folder filter need no token migration. No other client migration is required.

## Back up the store

Stop every process sharing the data directory before the first 0.28.0 process opens it. Fluxmail backs up the store before migrating it to format 9. Keep a [complete pre-upgrade backup](/docs/backup-and-restore), including the encryption key, because Fluxmail 0.27.0 cannot open a format 9 store. Rolling back requires restoring that backup.
